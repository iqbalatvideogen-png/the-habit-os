# Contributing to The Habit OS

## How to Contribute

Thank you for your interest in contributing to The Habit OS!

## Ways to Contribute

### 1. Content Contributions
- Suggest new habit chapters
- Improve existing content
- Add more research citations
- Create additional worksheets and templates

### 2. Code Contributions
- Improve the PDF generation script
- Add automation tools
- Enhance the build process

### 3. Design Contributions
- Create book cover design
- Design part divider images
- Create icons and illustrations
- Improve CSS styling

### 4. Testing & Feedback
- Test PDF generation
- Report bugs and issues
- Suggest improvements
- Provide feedback on content

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your changes
4. Make your contributions
5. Push to your fork
6. Submit a pull request

## Content Guidelines

### Chapter Structure
All chapters must include:
- Learning Objectives
- Research Insights
- Practical Applications
- Common Mistakes
- Myths vs Evidence
- Step-by-Step Implementation
- Reflection Questions
- Exercises
- Summary
- Action Checklist
- References
- Next Steps

### Writing Style
- Use clear, concise language
- Back all claims with research
- Include proper citations
- Use active voice
- Keep paragraphs short
- Use bullet points and lists

### Research Standards
- Use peer-reviewed sources when possible
- Cite all sources properly
- Prefer recent research (last 10 years)
- Include links to original sources

## PDF Generation

To generate the PDF version:

```bash
npm install
npm run generate-pdf
```

The PDF will be created in the dist/ directory.

## Reporting Issues

Use the GitHub issue tracker to report:
- Bugs in the PDF generation
- Content errors
- Formatting issues
- Feature requests
