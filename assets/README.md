# Assets Directory

This directory contains all visual assets for The Habit OS book.

## Structure

- `images/`: All images used in the book
  - `cover.png`: Book cover image
  - `part-dividers/`: Divider images for each part
- `css/`: CSS stylesheets
  - `styles.css`: Main stylesheet for the book
- `icons/`: SVG icons used throughout the book

## Usage

All images should be in PNG or SVG format for best quality.

### Image Requirements
- **Cover**: 1200x1800 pixels (2:3 ratio)
- **Part Dividers**: 1200x400 pixels (3:1 ratio)
- **Icons**: SVG format, scalable

### Color Scheme
- Primary: #2563eb (Blue 600)
- Secondary: #1e40af (Blue 800)
- Accent: #3b82f6 (Blue 500)
- Success: #10b981 (Green 500)
- Warning: #f59e0b (Amber 500)
- Danger: #ef4444 (Red 500)

### Typography
- Primary Font: Inter (Google Fonts)
- Fallback: System fonts

## Contributing

To add new assets:
1. Place images in the appropriate subdirectory
2. Use descriptive filenames
3. Optimize images for web (compress without losing quality)
4. Update this README if new categories are added
