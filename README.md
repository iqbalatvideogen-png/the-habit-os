# The Habit OS: Build a Life That Runs on Great Habits

> **A comprehensive, research-backed guide to mastering your habits and transforming your life**

## 📖 About This Book

The Habit OS is a comprehensive book designed to help you understand, build, and master habits that will transform every area of your life. With 51 chapters across 13 parts and 5 detailed appendices, this book provides a complete operating system for personal development.

## 🚀 Getting Started

### Read Online
Browse the markdown files in the `book/` directory.

### Generate PDF
```bash
git clone https://github.com/iqbalatvideogen-png/the-habit-os.git
cd the-habit-os
npm install
npm run generate-pdf
```

The PDF will be created in the `dist/` directory.
